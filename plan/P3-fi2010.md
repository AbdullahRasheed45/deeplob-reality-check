# P3: DeepLOB model and FI-2010 replication

**Goal:** reproduce the published DeepLOB results on FI-2010 with a clean, tested implementation, and document every difference from the reference code.

## 1. Download: `lobrc fi2010 download`
- URL: `https://raw.githubusercontent.com/zcakhaa/DeepLOB-Deep-Convolutional-Neural-Networks-for-Limit-Order-Books/master/data/data.zip`
- Save to `fi2010/data.zip`, unzip into `fi2010/`. Expect four files (shapes as rows x columns):
  - `Train_Dst_NoAuction_DecPre_CF_7.txt` 149 x 254,750
  - `Test_Dst_NoAuction_DecPre_CF_7.txt` 149 x 55,478
  - `Test_Dst_NoAuction_DecPre_CF_8.txt` 149 x 52,172
  - `Test_Dst_NoAuction_DecPre_CF_9.txt` 149 x 31,937
- Record the SHA-256 of each file in `results/fi2010/checksums.txt` on first download; on later runs verify and fail loudly on mismatch.
- Loading text with `np.loadtxt` is slow (the train file is about 600 MB). Load once, then cache as `fi2010/cache.npz` with arrays `train_x, train_y, test_x, test_y, test_day` (float32 for x, int8 for y).

## 2. Parsing: `src/lobrc/data/fi2010.py`
- `x = data[:40, :].T` gives float32 `[N, 40]`, already in FI order (ask px, ask size, bid px, bid size per level). Already normalised by the dataset authors ("DecPre" = decimal-precision normalisation). Do not normalise again.
- `y_raw = data[-5:, :].T` gives `[N, 5]` with columns for horizons `[10, 20, 30, 50, 100]` events, values in {1, 2, 3}: 1 = up, 2 = stationary, 3 = down. Map to internal classes with `{1: 2, 2: 1, 3: 0}`.
- Test set = the three test files concatenated in order 7, 8, 9; keep `test_day` = 0, 1, 2 for per-day metrics.
- **Validation split (faithful to reference):** the first 80% of training columns (`floor(0.8 * N)`) are train, the remaining 20% are validation, in time order. No shuffling across the boundary.
- `stock_boundaries(x) -> np.ndarray[bool]`: `True` at index i when `|mid_i - mid_{i-1}| / mid_{i-1} > 0.05`, with `mid = (x[:,0] + x[:,2]) / 2`. Day files concatenate 5 stocks per day. Log the number of boundaries found per file (expect 4 in `Test_..._7`).

## 3. Windowing: `src/lobrc/features/windows.py`
```python
class WindowDataset(torch.utils.data.Dataset):
    def __init__(self, x: np.ndarray, y: np.ndarray, anchors: np.ndarray, T: int = 100): ...
    def __getitem__(self, j):  # returns (torch.float32 [1, T, 40], torch.int64 scalar)
        t = anchors[j]; return x[t-T+1 : t+1][None], y[j]
```
- **Do not materialise all windows** (the reference does this in float64, about 6.5 GB for the train file). Store `x` once and slice per item.
- Faithful anchors: every `t` from `T-1` to `N-1` (as the reference `data_classification`, which pairs window ending at t with label at t).
- Clean anchors: additionally exclude any window `[t-T+1, t]` that contains a stock boundary (`stock_boundaries` True at any index in `(t-T+1, t]`).
- `make_anchors(n, T, boundaries=None, stride=1) -> np.ndarray[int64]`.

## 4. Model: `src/lobrc/models/deeplob.py`
Implement exactly this (matches the reference PyTorch notebook layer by layer):

| Block | Layers (in order) |
| --- | --- |
| conv1 | Conv2d(1,32,(1,2),stride=(1,2)); LeakyReLU(0.01); BN(32); Conv2d(32,32,(4,1)); LeakyReLU(0.01); BN(32); Conv2d(32,32,(4,1)); LeakyReLU(0.01); BN(32) |
| conv2 | Conv2d(32,32,(1,2),stride=(1,2)); Tanh; BN(32); Conv2d(32,32,(4,1)); Tanh; BN(32); Conv2d(32,32,(4,1)); Tanh; BN(32) |
| conv3 | Conv2d(32,32,(1,10)); LeakyReLU(0.01); BN(32); Conv2d(32,32,(4,1)); LeakyReLU(0.01); BN(32); Conv2d(32,32,(4,1)); LeakyReLU(0.01); BN(32) |
| inp1 | Conv2d(32,64,(1,1),padding="same"); LeakyReLU; BN(64); Conv2d(64,64,(3,1),padding="same"); LeakyReLU; BN(64) |
| inp2 | Conv2d(32,64,(1,1),padding="same"); LeakyReLU; BN(64); Conv2d(64,64,(5,1),padding="same"); LeakyReLU; BN(64) |
| inp3 | MaxPool2d((3,1),stride=(1,1),padding=(1,0)); Conv2d(32,64,(1,1),padding="same"); LeakyReLU; BN(64) |
| head | concat(inp1,inp2,inp3) on channels gives 192; permute(0,2,1,3) and reshape to [B, T', 192]; LSTM(192, 64, 1 layer, batch_first=True) with zero initial state; take last time step; Linear(64, 3) |

- `forward(x)` returns **logits** `[B, 3]` (no softmax). Provide `predict_proba(x) = softmax(forward(x))`.
- Shapes for input `[B, 1, 100, 40]`: after conv1 `[B,32,94,20]`, conv2 `[B,32,88,10]`, conv3 `[B,32,82,1]`, inception concat `[B,192,82,1]`, LSTM input `[B,82,192]`, output `[B,3]`.
- **Trainable parameter count = 143,907** (conv1 8,544; conv2 10,528; conv3 18,720; inp1 14,720; inp2 22,912; inp3 2,240; LSTM 66,048; fc 195). If your count differs, re-derive by hand before changing the architecture, and record the reason in `DECISIONS.md`.
- Constructor flag `apply_softmax_in_forward: bool = False`. When True, `forward` returns `softmax(logits)`, reproducing the reference quirk (its loss then applies log-softmax on top of softmax). Used only for the `faithful` run.
- Works for any `T >= 19` (the time axis shrinks by 18). Assert this in `__init__`.

Tests (`tests/test_deeplob.py`): shape test on `[2,1,100,40]`; parameter count equals 143,907; intermediate shapes via forward hooks match the table; `predict_proba` rows sum to 1; with `apply_softmax_in_forward=True` outputs are in [0,1]; the model overfits a tiny batch (16 samples, 200 steps, Adam 1e-3) to training accuracy 1.0 (catches wiring bugs).

## 5. Training: `src/lobrc/train.py`, CLI `lobrc train --config configs/fi2010.yaml`
Generic trainer used by P3 and P5:
- Optimizer Adam (`lr`, default 1e-4, betas default), batch size 64, `epochs` 50, shuffle train each epoch with seeded generator, `num_workers` 2, `pin_memory` when CUDA.
- Loss: `nn.CrossEntropyLoss()` on the model output. (In the faithful run the output is the softmax, reproducing the quirk.)
- After each epoch: validation loss and validation weighted F1. Save `best.pt` when validation loss improves (same selection rule as the reference). Early stopping is **off** for FI-2010 (reference trains all 50 epochs) and configurable for crypto (`early_stop_patience`).
- Save `state_dict` only (not the whole pickled model), plus `model_config.json`.
- Device: `cuda` if available, else `mps`, else `cpu`. Log epoch time. Mixed precision off (keeps results deterministic).
- Log per epoch to `log.txt` and `history.csv` (`epoch, train_loss, val_loss, val_acc, val_f1_weighted, secs`).

`configs/fi2010.yaml`:
```yaml
inherits: default.yaml
task: fi2010
data: {T: 100, horizons_idx: [0, 1, 3, 4], anchors: faithful}   # 0->k10, 1->k20, 3->k50, 4->k100
model: {name: deeplob, apply_softmax_in_forward: false}
train: {lr: 0.0001, batch_size: 64, epochs: 50, early_stop_patience: null, seeds: [1234, 1, 2]}
```

## 6. Evaluation: `src/lobrc/evaluate.py`, CLI `lobrc evaluate --run <run_dir>`
Metrics on the test set with the best checkpoint:
- accuracy; precision, recall and F1 with `average="weighted"` **and** `average="macro"` (scikit-learn). The paper's precision/recall/F1 are weighted averages (weighted recall equals accuracy, which matches the paper's tables); compare to the paper using weighted F1.
- confusion matrix (rows = true, cols = predicted, internal class order down/flat/up); per-test-day metrics.
- Save `predictions.parquet` with `index, y_true, p_down, p_flat, p_up`.

## 8. Reporting: `lobrc fi2010 summarize`
Writes `results/fi2010/summary.md` and `summary.csv`: one row per (variant, horizon) with mean and standard deviation across seeds of accuracy, weighted F1 and macro F1; a column with the published weighted F1 (k=10: 83.40, k=20: 72.82, k=50: 80.35; k=100: compare with the reference notebook's saved result, accuracy 75.35 and macro F1 75.33); and the difference. Add a paragraph noting:
- the softmax quirk and its measured effect (faithful vs fixed),
- the effect of excluding cross-stock windows (clean vs fixed),
- that FI-2010 labels cannot be exactly recomputed from the released prices (sign agreement only about 0.67-0.73 with a "future mean vs past mean" definition), and that labels use a smoothed future mid-price, which makes them easier to predict than a tradable price change.
